# Gitagotchi 사용자 설명서

Gitagotchi는 VS Code 안에서 개발 활동을 펫 성장으로 바꿔 주는 확장입니다. 코드를 수정하고, 커밋하고, 진단 문제를 줄이고, 문서와 테스트를 작성하면 경험치, 퀘스트 진행도, 레이드 피해량, 시즌 점수, 장식 보상이 누적됩니다.

별도의 게임을 플레이하는 방식이 아닙니다. 평소처럼 개발하고, Gitagotchi 패널을 열어 오늘의 성장과 다음 목표를 확인하면 됩니다.

## 시작하기

1. VS Code에서 Git 저장소 워크스페이스를 엽니다.
2. 처음 실행할 때 Gitagotchi 이름을 입력합니다.
3. 상태 표시줄의 Gitagotchi 항목을 클릭하거나 `Gitagotchi: Open Pet` 명령을 실행합니다.
4. `목표` 탭에서 오늘의 퀘스트를 하나 선택합니다.
5. 평소처럼 코드 수정, 커밋, 진단 문제 해결, 문서 작성, 테스트 추가를 진행합니다.
6. 다시 패널을 열어 성장, 퀘스트, 레이드, 보상, 수집 현황을 확인합니다.

Git 저장소 밖에서도 패널은 열 수 있지만, 성장 보상은 Git 워크스페이스에서 가장 잘 동작합니다.

## 패널 구조

패널은 왼쪽 펫 카드와 오른쪽 시스템 카드로 나뉩니다.

펫 카드에서는 다음 정보를 확인합니다.

- 펫 외형, 이름, 레벨, 성장 단계, 계열, 전문성
- 장착 중인 장식
- 환생으로 얻은 별
- 현재 경험치 진행도

시스템 카드는 네 개의 탭으로 구성됩니다.

- `상태`: 핵심 능력치, 경험치, 진화 미리보기, 계열 스킬, 스타일 점수
- `목표`: 오늘의 퀘스트, 직업 훈련, 워크스페이스 협동 레이드
- `엔드게임`: 마스터리, 시즌, 직업 빌드, 레이드 보스, 시즌 보상 트랙, 별 투자 트리, 별 조각 제작, 환생
- `수집`: 장식 컬렉션 북, 레이드 클리어 기록, 프로젝트 프로필, 주간 회고

데스크톱 화면에서는 활성 탭 하나만 스크롤됩니다. 엔드게임 탭 안쪽에 중첩 스크롤이 생기지 않도록 설계되어 있습니다.

## 주요 버튼

상단 액션 버튼은 다음 역할을 합니다.

- `만져주기`: 하루 한 번 보너스 경험치와 기분을 얻습니다.
- `커밋 확인`: 최신 커밋을 확인하고 커밋 성장 이벤트를 적용합니다.
- `통계 보기`: 활동 로그와 보상 기록을 엽니다.
- `스킬`: 스킬 패널을 엽니다.
- `도감`: 발견한 Gitagotchi 형태를 확인합니다.
- `부활`: 죽은 펫을 누적 경험치로 되살립니다.

헤더 버튼은 다음 역할을 합니다.

- `이름 변경`: 펫 이름을 바꿉니다.
- `초기화`: 현재 펫 루프를 초기화합니다. 발견한 도감 항목은 유지됩니다.
- `?`: 패널 도움말을 엽니다.
- 언어 버튼: 영어, 한국어, 일본어, 중국어로 UI 언어를 바꿉니다.

## 성장과 능력치

Gitagotchi는 다음 개발 활동으로 성장합니다.

- 코드 변경: 변경 줄 수와 파일 수에 따라 경험치를 얻습니다.
- 커밋: 기본 경험치와 함께 `feat`, `fix`, `hotfix`, `refactor` 메시지 보너스를 받을 수 있습니다.
- 진단 문제 해결: VS Code 진단 문제 수를 줄이면 디버깅 보상을 얻습니다.
- 리팩터링: 삭제가 추가보다 많은 정리형 변경에서 보상을 얻습니다.
- 테스트, README, 설정 파일 변경: 각각 별도 보너스를 얻습니다.
- 방치 후 복귀: 일정 시간 뒤 다시 작업하면 에너지가 일부 회복됩니다.
- 장시간 방치: 일부 펫 상태가 낮아질 수 있습니다.

반복 보상 악용을 줄이기 위해 같은 활동은 보상이 감쇠될 수 있고, 프로젝트별 일일 경험치 상한도 적용됩니다.

## 진화

펫은 레벨과 케어 상태, 스타일 점수를 기준으로 진화합니다.

- `알`: 시작 단계입니다.
- `해츨링`: 레벨 2부터 도달합니다.
- `툴킷`: 레벨 5와 안정적인 케어 상태가 필요합니다.
- `스페셜리스트`: 레벨 15, 더 높은 케어 상태, 생존 상태가 필요합니다.
- `궁극`: 레벨 30, 충분한 활동량, 균형 잡힌 스타일 점수, 높은 케어 상태가 필요합니다.

`상태` 탭의 진화 미리보기에서 다음 단계에 필요한 조건을 확인할 수 있습니다.

## 오늘의 퀘스트

매일 세 개의 퀘스트 후보가 표시됩니다. 하나를 선택하면 해당 퀘스트가 오늘의 목표가 됩니다.

퀘스트 종류는 다음과 같습니다.

- `버그 사냥`: 진단 문제를 줄입니다.
- `정리의 날`: 삭제가 추가보다 많은 정리형 변경을 만듭니다.
- `현장 가이드`: 문서나 텍스트 파일을 수정합니다.
- `출하 준비`: 커밋을 완료합니다.
- `균형 훈련`: 가장 낮은 스타일 점수를 보완하는 활동을 합니다.

퀘스트를 완료하면 경험치, 기분, 장식을 얻습니다.

## 직업 빌드

직업은 고레벨 사용자가 자신의 개발 성향을 선택하고 강화하는 시스템입니다.

- `릴리즈 마스터`: 빌드와 배포 중심
- `코드 정원사`: 정리와 리팩터링 중심
- `버그 추적자`: 진단 문제와 버그 수정 중심
- `아키비스트`: 문서와 기록 중심
- `밸런스 아키텍트`: 균형 성장 중심

직업을 선택하면 직업 보너스와 직업 훈련이 활성화됩니다. 직업 변경에는 경험치가 필요합니다.

## 레이드

레이드는 고레벨 사용자를 위한 장기 목표입니다. `엔드게임` 탭에서 보스를 선택한 뒤 평소처럼 개발하면 관련 활동이 보스에게 피해를 줍니다.

레이드 보스는 다음과 같습니다.

- `레거시 드래곤`: 리팩터링과 정리에 약합니다.
- `버그 군주`: 진단 문제 해결에 약합니다.
- `릴리즈 골렘`: 커밋과 테스트 작업에 약합니다.
- `의존성 망령`: 설정과 의존성 작업에 약합니다.
- `브레이크포인트 히드라`: 시즌 한정 보스이며 문서, 테스트, 시즌 진행에 약합니다.

보스를 격파하면 레이드 기록이 남고 보스 장식을 얻습니다.

## 시즌, 협동 레이드, 프로젝트 프로필

시즌 점수는 개발 활동을 통해 누적됩니다. 100점, 250점, 500점에서 시즌 마일스톤 보상을 얻고, 500점에서는 시즌 유물을 얻을 수 있습니다.

`목표` 탭의 워크스페이스 협동 레이드는 활동 경험치에 따라 기여도가 쌓입니다. 목표치를 채우면 클리어 보상을 얻습니다.

프로젝트 프로필은 워크스페이스별 경험치와 레이드 클리어 기록을 저장합니다. 여러 프로젝트에서 오래 사용한 흔적을 확인할 수 있습니다.

## 별 조각, 환생, 별 투자 트리

`엔드게임` 탭에서는 장기 성장 시스템을 사용할 수 있습니다.

- `별 조각 제작`: 조건을 만족하면 경험치를 사용해 별 조각을 제작합니다.
- `환생`: 레벨 30 궁극 단계에서 생존 중일 때 사용할 수 있습니다.
- `별 투자 트리`: 환생으로 얻은 별을 영구 보너스에 투자합니다.

환생하면 현재 생애의 레벨, 현재 경험치, 진행 중인 레이드 등은 초기화되지만 별, 도감 발견, 장식, 장기 기록은 유지됩니다.

별 투자 트리는 다음 노드를 가집니다.

- `레이드 위력`: 레이드 중심 성장에 도움을 줍니다.
- `안정 케어`: 케어 상태 유지에 도움을 줍니다.
- `시즌 기억`: 시즌 진행에 도움을 줍니다.

## 장식과 수집

장식은 사용자의 성취를 남기는 수집 보상입니다.

장식은 다음 경로로 얻을 수 있습니다.

- 오늘의 퀘스트
- 직업 훈련
- 레이드 격파
- 시즌 마일스톤
- 엔드게임 장기 행동

`수집` 탭에서 장식 컬렉션 북, 레이드 기록, 프로젝트 프로필, 주간 회고를 확인할 수 있습니다. 펫 카드의 보유 장식을 클릭하면 장착하거나 해제할 수 있습니다.

## 도감

도감은 발견한 Gitagotchi 형태를 기록합니다. 성장 단계, 계열, 전문성, 궁극 형태에 도달하면 새로운 형태가 발견됩니다.

펫을 초기화해도 이미 발견한 도감 항목은 유지됩니다.

## 명령어

명령 팔레트에서 사용할 수 있는 명령은 다음과 같습니다.

- `Gitagotchi: Open Pet`
- `Gitagotchi: Rename Pet`
- `Gitagotchi: Reset Pet`
- `Gitagotchi: Pat Pet`
- `Gitagotchi: Revive Pet`
- `Gitagotchi: View Stats`
- `Gitagotchi: View Skills`
- `Gitagotchi: Open Dex`
- `Gitagotchi: Check Commit`

퀘스트 선택, 직업 선택, 레이드 시작, 별 투자, 장식 장착, 주간 회고 복사, 환생 같은 고급 행동은 명령 팔레트가 아니라 펫 패널 안에서 실행합니다.

## 저장과 초기화

Gitagotchi 상태는 VS Code 전역 저장소에 저장됩니다. 같은 환경에서 VS Code를 다시 열면 이전 상태가 유지됩니다.

초기화하면 다음 항목이 초기화됩니다.

- 이름
- 레벨과 현재 경험치
- 케어 상태
- 현재 성장 단계와 정체성
- 스킬
- 최근 활동 로그

초기화해도 다음 항목은 유지됩니다.

- 이미 발견한 도감 항목

환생은 초기화보다 더 많은 장기 성장을 유지합니다.

- 환생 별
- 도감 발견
- 장식과 수집 진행도
- 장기 엔드게임 기록
